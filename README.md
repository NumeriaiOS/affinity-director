# Qloo Agentic Hackathon Project

Working repository for the Qloo Agentic Hackathon (deadline: 2026-10-30).

## Product direction

Provisional concept: **Affinity Director** — an agentic cultural-planning system that turns a target audience's cross-domain tastes into a coherent experience plan (music, venue/place context, food, brands, aesthetics and supporting activities), grounded in Qloo rather than generic LLM guesses.

## Repository layout

- `backend/` API/orchestration service
- `frontend/` public demo UI
- `docs/` product, architecture and experiment notes
- `scripts/` development utilities

## Security

Do not commit API keys. Copy `.env.example` to `.env` locally when credentials are available.
